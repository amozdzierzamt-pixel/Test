# 🐸 Skacząca Żaba

Gra przeglądarkowa w stylu Flappy Bird — w roli głównej żaba z kołem ratunkowym, skacząca między rurami zjeżdżalni basenowych.

Stworzona dla **Gminnych Basenów Rekreacyjnych w Radomyślu Wielkim**.

## Jak zagrać

Otwórz plik `index.html` w przeglądarce — to wszystko, gra nie ma żadnych zależności.

## Sterowanie

- **Spacja** / **strzałka w górę** — skok
- **Klik myszką** lub **dotknięcie ekranu** — skok (działa na telefonach)

## Zasady

- Przeprowadź żabę między rurami zjeżdżalni — każda minięta para to 1 punkt.
- Nie dotknij rury i nie wpadnij do basenu, bo… PLUSK! 💦
- Najlepszy wynik („Rekord basenu") zapisuje się lokalnie w przeglądarce.

## Hosting

Wystarczy wrzucić `index.html` na dowolny serwer WWW (np. GitHub Pages albo stronę gminy).
